# 武汉科技大学博士论文理工类参考文献版式核对说明

## 依据和适用范围

依据用户提供的《附件5-1 博士 论文编排式样（理工类）.doc》，完整读取正文后，以文件第 15 页起的“参考文献”和“参考文献说明”为主要依据。源文件 SHA-256：`5934290b7e9fefb785c998bb5247f936ab29449e1567f85bba341bd8c4d028f4`。这是附件模板对应的版式，不将其表述为经过校方网站验证的最新版全校规范。

文件：`styles/wust-doctoral-science.style`，ID：`wust-doctoral-science`，需要 AcNote 0.1.22 或以上。版式独立包含全部模板，不依赖另一个用户版式。

作用范围是文中引用与文末参考文献；封面、正文标题、页眉页脚、目录、公式、图表和附录不是参考文献版式的作用范围，须继续使用学校原始论文模板。

## 已实现规则

- 文末以 `[1]`、`[2]` 等数字顺序编号。Word 原文件中的这些编号是自动列表，已读取列表属性核实。
- 作者不超过 3 位全部列出，超过 3 位列前 3 位；中文后接 `，等`，英文后接 `, et al.`。
- 英文作者姓在前、名字首字母缩写在后，缩写字母间有空格，不添加缩写点；姓氏保持文献数据中的大小写。
- 英文题名按句首大写输出，已有全大写缩略词和内部大写技术名保留；专有名词需要作者复核。期刊名按英文标题形式输出，介词、冠词和连接词不强行大写。期刊名称必须填写全称，软件不会猜测或扩展未知缩写。
- 列表正文宋体、Times New Roman，小四号（12 pt），1.25 倍行距，段前段后 0，两端对齐。悬挂缩进采用中文参考文献示例的 21 pt；原英文示例是约 28.35 pt，附件没有统一文字规定，因此不把该单条差异推广为全校要求。
- 管理“参考文献”标题：黑体小二号（18 pt）、加粗居中，段后 1 行、另起页。标题包含在可刷新的参考文献块里，跳转目标从首条文献开始，不指向标题。如稿件已经有手工标题，应避免重复。
- 公告日期、引用日期、专利发布日期按原数据输出，建议完整填写 `YYYY-MM-DD`。
- 不默认添加附件没有要求的 DOI 或网页信息；只有在线文献、未发表预印本使用 URL 模板。

## 全角与半角

| 用途 | 中文 | 英文 |
| --- | --- | --- |
| 作者之间 | `，` U+FF0C | `, ` U+002C 后跟空格 |
| 编者后、出版者与年份之间 | `，` | `, ` |
| 出版地后、页码前 | `：` U+FF1A | `: ` U+003A 后跟空格 |
| 期号括号 | `（` / `）` U+FF08 / U+FF09 | `(` / `)` U+0028 / U+0029 |
| 公告日期圆括号 | `（` / `）` | `(` / `)` |
| 句点、文献类型方括号、日期方括号 | `.`、`[J]`、`[YYYY-MM-DD]`，均为半角 | 相同 |
| 页码区间 | `-` U+002D | 相同 |
| 析出文献连接 | `∥` U+2225 | 相同 |

元数据本身的文字标点保留原值，例如书名中的全角冒号和标准编号中的破折号；上述规则只应用于版式产生的著录标识符。

## 各类文献与补充字段

| AcNote 类型 | 附件覆盖项 | 补充著录字段 |
| --- | --- | --- |
| `article-journal` | 期刊文章 `[J]` | 无；填写完整刊名、卷、期、页码 |
| `book` | 专著 `[M]`，也可包含译者 | 译者（可选） |
| `translated-book` | 译著 `[M]` | 译者 |
| `proceedings` | 整本会议论文集 `[C]` | 没有作者时填写编者 |
| `paper-conference`、`chapter` | 析出文献 `[C]∥` | 原文献编者；会议/原文献题名填在来源栏 |
| `thesis` | 学位论文 `[D]` | 出版地为保存城市，出版者为保存单位 |
| `patent` | 专利 `[P]` | 国别、专利号、发布日期 |
| `standard` | 技术标准 `[S]` | 标准编号 |
| `report` | 技术报告 `[R]` | 报告编号（有则填） |
| `webpage` | 在线文献 `[EB/OL]` | 公告/更新日期、引用日期 |
| `document` | 其他来源的保守回退 `[Z]` | 附件未给出该类范例，不应代替已知类型 |
| `preprint` | 附件未规定未发表预印本的具体著录格式 | 需要填写正式版本核验说明，已发表时改成正式文献类型 |

补充著录字段会按当前类型和版式自动出现在文献信息编辑区域，不需要手工修改数据库。文献库内部扩展键分别为 `translator`、`editors`、`country`、`patent-number`、`standard-number`、`report-number`、`publication-date`、`updated`、`accessed`、`formal-version-check`。

## 原模板中不一致处的处理

1. 中文期号括号：说明行使用 `(期)`，但完整中文示例明确写 `29（1）`。本版式按中文完整示例用全角、英文用半角。
2. 期刊名后的标点：中文完整示例为逗号，英文完整示例为句点，分别保留；不是统一全部改成英文逗号。
3. 中文期刊的 `[J].` 后：完整示例无空格，说明行有空格。本版式按完整示例保留无空格；其他类型按各自示例处理。
4. 会议论文集页码：完整示例用年份后冒号，说明行用句点。本版式按完整示例使用冒号。
5. 原网页示例把网址中的 `//` 排为 `∥`。这会破坏可用链接，生成网址保留元数据中的 `http://` 或 `https://`，不将 URL 替换成析出文献分隔符。
6. 附件没有给出正文中引用的上标/基线、连续编号压缩等详细说明。文中采用 AcNote 顺序编码默认的上标方括号，区间用半角连字符；这属于软件默认，不声称为附件明确要求。
7. 附件明确规定“已公开发表的文献不得用预印版链接格式引用”。版式不擅自把预印本伪装成期刊文章；正式出版情况和所用版本需要核验。软件不能仅凭本地元数据断言论文是否已经发表。

## 验证

自动测试逐字符对照模板中的 11 条完整文献示例，包括中英文期刊、专著、译著、会议论文集、析出文献、学位论文、专利、标准、报告和在线文献。网址协议按上面的说明保留有效形式。

另外，在隐藏 Word 的独立临时文档中验证标题字体、12 pt 正文、1.25 倍行距、刷新幂等、标题偏移后的书签跳转，以及切换回普通版式后清理托管标题。测试输出的 PDF 与原模板第 15 页已渲染对照检查。
